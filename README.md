# collab-doc
CollabDoc 是一个多人实时协作文档编辑平台，类似轻量版 Notion。解决了团队协作中文档版本混乱、多人编辑冲突、知识分散难检索的问题。支持多人同时编辑同一文档并实时同步，提供文件夹层级管理、全文搜索、版本历史回溯、Markdown 导入导出和 AI 辅助写作，帮助团队在一个平台上高效地创作、组织和查找文档。
